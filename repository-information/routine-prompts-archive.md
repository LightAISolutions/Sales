# Routine prompts — archive of the pre-rebuild originals

*Verbatim prompt text of the four agent-created Routines deleted on 2026-09-22, kept because a Routine
prompt has no export and no version history: once the Routine is gone, so is the text.*

*Why they were deleted: `create_trigger` cannot attach a repository, so every agent-created Routine fired
into a session with no checkout and could never push. Each was rebuilt through the claude.ai form, the only
surface with a repository picker. Full investigation in `ROUTINES-OPERATIONS.md`.*

*These are **not** the live prompts.* The running Routines carry revised text — notably the quarterly sweep,
whose hardcoded 21-company list was replaced by a tier read against the refresh calendar. The value kept here
is the per-company research detail: most of it moved into each calendar row's `watch[]`, but the migration
summarised in places (`crusoe` lost its named specifics — Abilene, the ~900 MW Microsoft deal, GE Vernova,
Bergen, Form Energy), so this file is where that detail survives.

*No credential appears below. The text was machine-scanned before it was written, and the earnings desk — the
only Routine whose prompt carries a real corpus token — is deliberately excluded. C2's `CORPUS TOKEN: none is
supplied` is an explicit absence, not a secret.*
